# Supervised Classification Modeling & Tuning

A beginner-friendly machine-learning portfolio project that trains and compares four classification algorithms, tunes hyperparameters, evaluates validation metrics, plots ROC curves and a confusion matrix, and saves the selected champion model.

## Models included
- Logistic Regression
- Random Forest
- Gradient Boosting
- Extra Trees

## Implementation
- Dataset: Scikit-learn's built-in Breast Cancer Wisconsin dataset
- Train/validation split: stratified 80/20 split
- Hyperparameter optimization: `GridSearchCV`
- Cross-validation: stratified 5-fold
- Metrics: Accuracy, Precision, Recall, F1-score, ROC-AUC
- Visualizations: ROC curves and champion confusion matrix
- Model export: `champion_model.joblib`
- Comparison report: `model_comparison.csv`

## Run in Google Colab
1. Upload `supervised_modeling_and_tuning.ipynb` to Google Colab.
2. Run all cells from top to bottom.
3. Download or save the generated `champion_model.joblib` and `model_comparison.csv`.

## Run locally
```bash
python -m venv .venv
```
Windows:
```bash
.venv\Scripts\activate
```
macOS/Linux:
```bash
source .venv/bin/activate
```
Install packages:
```bash
pip install -r requirements.txt
jupyter notebook
```
Open `supervised_modeling_and_tuning.ipynb` and run all cells. The model and comparison CSV are saved in the current working directory.

## Repository files
- `supervised_modeling_and_tuning.ipynb` — full training, tuning, evaluation, plots, and export workflow
- `champion_model.joblib` — trained model artifact, generated by this project
- `model_comparison.csv` — validation metrics comparison
- `requirements.txt` — dependencies
- `.gitignore` — common Python/Jupyter exclusions

## Important limitations
This is an educational project using a bundled public dataset. It is not a medical diagnostic system and must not be used for clinical decisions. Validation scores depend on the chosen split and environment. For a real deployment, add domain review, fairness checks, calibration, monitoring, and external validation.
